# Standardized Question Bank & Exam Repository

This directory contains official exam question banks organized following the standard naming convention:

```
[SUBJECT]-[STANDARD]-[TOTALQUESTIONS]-[SET_NUMBER].json
```

### Examples:
* `CHEMISTRY-12-50-SET1.json`: Class 12 Chemistry, 50 Questions, Set 1 (Bilingual TN State Board)
* `CHEMISTRY-12-50-SET2.json`: Class 12 Chemistry, 50 Questions, Set 2 (Bilingual TN State Board)
* `CHEMISTRY-12-100-ALL.json`: Class 12 Chemistry, 100 Questions, Complete Full Bank
* `MATHEMATICS-10-14-SET1.json`: Class 10 Mathematics, 14 Questions, Set 1
* `PHYSICS-12-15-SET1.json`: Class 12 Physics, 15 Questions, Set 1
* `COMPUTER_SCIENCE-12-15-SET1.json`: Class 12 Computer Science, 15 Questions, Set 1

Whenever questions are shared or generated, they will be archived here in this standard JSON structure.
